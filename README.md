# hash

Atividade sobre hash desenvolvida na disciplina Segurança em Sistemas de Informação.
O programa compara duas implementações didáticas de hash de 32 bits: XOR bloco a
bloco e XOR com rotação de bits.

## Pré-requisitos

- [Node.js](https://nodejs.org/) instalado.

## Como executar

No terminal, na pasta do projeto, execute:

```bash
node main.js
```

O programa imprime os resultados dos dois algoritmos para quatro entradas de
teste, incluindo exemplos com pequenas diferenças e blocos repetidos.

## Como foi implementado

Código gerado com o `Gemini AI`, da Google. O modelo utilizado foi o `Argon` com nível de raciocínio no máximo.

Prompt usado:

```
"Você é um especialista em Segurança em Sistemas de Computação. Você me ajudará com atividades práticas da disciplina na universidade. Preciso que me explique didaticamente o que cada atividade pede e depois implemente o que é pedido em JAVASCRIPT.

Atividade 9 Hash

Gerar um código simples de hash baseado em algo simples, como: utilizando somente XOR bloco a bloco, XOR com rotação, etc."
```
